# Runtime dependencies for Vercel.
#
# Vercel's Python builder installs from requirements.txt; it does not read
# pyproject.toml. Without this file the backend deploys as a project with no
# dependencies and every import fails at runtime.
#
# Kept minimal on purpose: only what the API actually imports at runtime.
# Test-only packages (pytest, pytest-asyncio) live in pyproject.toml [dev] and
# are not needed in the deployment.
#
# Regenerate locally with:
#   .\.venv\Scripts\python.exe -m pip freeze
